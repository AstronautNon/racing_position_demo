## 下半场（同一天）：查实"位置离群"真因，新增第三条姿态判据

上次记的那条待办（reject 的绝对阈值要按时间基准调）**查实后完全不成立**，
而且推翻了我自己给出的归因。

### 真因：水雾尾迹并进掩膜，把质心拖偏

video15 剔的 12 帧全在开头 k=1~13。逐帧看位移表发现疑点：
**k=13→14 位移 159 px（k=13 被剔）与 k=14→15 位移 167 px（k=14 未剔）同量级。**
原因是 `reject_pose_outliers` 用「偏离滑动中值」判别，而**滑动中值对单调序列
恒给出残差 ≈ 0** —— 位移再大也不判离群；k=1~13 被剔是因为那段轨迹**恰好 V 形折返**。
这是巧合，不是判据有效。

**真因**（逐帧目检 + 高饱和蓝掩膜独立测量双重确认）：车快速拖动时拉出的
**水雾/阴影尾迹**与车身差异同样强，被并进同一掩膜，质心被拖向尾迹侧。
实测 k=1~13 偏 **11~90 px**、k=15~19 偏 3~13 px、k=20+ 偏 2~6 px。
**k=14 偏 63 px 却漏剔，而它恰是人工标注的第一帧。**
量化影响：把 k≤14 的位置换成车体中心重算，**Δβ ≈ 8°**（k=14~17）。

### 关键洞察

**位置序列平滑 ≠ 位置正确。** 这类污染是"平滑地偏"，所以**任何位置跳变式判据
原理上都发现不了**（改 Hampel 也没用，局部尺度会跟着变大）。
可靠的替代需要"车与地面/尾迹颜色可分"这个前提，不通用 ——
`detect.contour_mask` 实测在 k=14 漏判、k=55~81 又虚报，**故不接入流水线**。

### 顺带发现的真问题：video12 的运动方向没有信息量

比各素材检测稳定性时 video12 一眼异常（面积 CV 0.672、速度中位 56 px/s、
64% 的帧 <100 px/s）。新增**第三条判据**：自适应位移信噪比

```
SNR = speed·dt / σ_pos     （σ_pos 由「原始位置 − 平滑位置」的高频残差估计）
```

实测：五段 SNR 中位 6.5~36、零异常；**video12 为 1.17，38/55 个标注帧 SNR<3**
（σ_pos 2.79 px vs 帧间位移中位 3.27 px）。它的 β 失来源**不是标注**，
是 `β = ψ_body − ψ_vel` 的后一半：车慢 + 质心抖，两者同量级。

同时更正 §14.10 的旧说法："video12 有 39% 的 β 空洞" —— **实际只 3% 是 NaN**
且不覆盖标注帧；k=14~60 那段不是"空"，是"有值但由噪声决定"。

### 顺带查出一个真 bug：裁图原点漏减黑边裁移

起因是 §14.15 里 video01 的"人工中点 vs 检测质心 = 316 px"，看着像检测坏了。
把标注轴**按检测质心画回车上**（一劳永逸的一步）：**方向完全正确**，
说明标注和检测都没错，是**坐标系**不一致。逐帧量 Δ，中位 **+311 px、σ 32**
⇒ 刚性平移 ⇒ 坐标系问题。

根因在 `crops.render()`：

```python
fx0 = round(x0*sxf) + l      # 工作图→原图，+l 正确
ox  = fx0c / sxf             # ← 错：原图坐标当工作图坐标用，漏减 l
# 正确：ox = (fx0c - l)/sxf
```

video01 黑边 l=676、sxf=2.001 ⇒ 偏 **337.8 px**，与实测同量级。

**影响面**：`axis_deg` 不受影响（平移不改变方向）→ 插值/β/报告数字/QA 全都正确；
受影响的是 CSV 里的 `x1..y2`，以及标注台**提示线**的显示位置
（video01 偏 676 显示 px > 裁图宽 634 px ⇒ 整条画到图外，被夹到边缘。
**这解释了为什么 video01 的标注清一色 manual** —— 那条提示没法用）。
