### 复核结论：标注是对的，判据是错的

三条独立证据（都不依赖被质疑的那条推理）：

1. **目检**（标注台同款裁图与坐标换算，`figures/video15_axis_compare_k14_16.jpg`）：
   k=14/15/16 车体长轴目测 ≈ **35° / −3° / 127°**，与人工标注
   **39.1° / −5.4° / 119.7°** 吻合；与 PCA 提示 **147.8° / 148.5° / 139.3°** 差 70°+。
2. **序列形态**：人工轴从 k=14 到 k=24 **单调递减**（39.1→…→−87.9，mod 180），
   是一次连贯的快速自转，不是来回误点。
3. **β 甩动的来源**：该区间 ψ_vel 的名义速度从 3131 掉到 66 px/s，
   低速帧方向估计被噪声主导 → 问题在**位置跟踪**，不在轴。

### 教训

**帧间速率 = 角度变化 × 时间基准。** 想把速率当"数据有错"的证据之前，
必须先确认时间基准。更一般地：任何把**元数据假设**当默认值的判据，
先问一句"这个假设在本素材上成立吗"。
