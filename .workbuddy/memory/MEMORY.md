# 漂移评分系统 · 项目长期记忆

> 详细规则见 `README.md`（十二个关键约定）与 `项目规划.md` §14。这里只放最容易踩的几条。

## 数据来源的可靠性分级

- **车身朝向 ψ_body 唯一可靠来源 = 人工标注**（`outputs/annotations/*.csv`）。
  掩膜 PCA 主轴只能当**粗初值**：掩膜实际是"运动月牙"而非车身轮廓，
  会把地面暗带/车身投影吃进去，实测 video15 上被**系统性带偏约 30°**（且随姿态变化）。
- **车头朝向是"推出来的"，不是观测来的**（`undirected_resolve` 取与运动方向夹角 ≤90° 的一端），
  故 β 被结构性夹在 (−90, 90]；真·|β|≥90 时车头判反而曲线看不出异常。

## 判据之前先问前提

- **时间基准**：素材是不是实时，登记在 `src/config.py` 的 `VideoSpec.realtime`。
  `False`（如 video15，原片加速过）时，`°/帧`、`°/s`、`px/s`、`t` 全是**名义值**，
  不准用来推断"数据有错"。加速倍率未知就不要臆造换算系数。
- 素材的一切元数据（机位、检测器、裁切、mask 带、realtime）**一律登记在 `config.py`**，
  不要散落到各处代码里。

## 容易写错的度量

- 量"两条无向轴的差"必须用 `kinematics.axis_dist`（折 90°）；
  用 `angle_diff`（折 180°）会把 0° vs 179°（其实差 1°）报成 179°。
- 标注一致性报告要**中位与 p90 并列**，只报中位数会把 80.78° 的 p90 藏住。

## 标注队列的操作红线

- 已全部标注的队列**冻结**；未完成的与旧队列**取并集**。
  不要为了"让队列更整齐"重生成 —— 实测会把已标帧挤出队列，让人白标一遍
  （标注数据不丢，但队列不再对应人工作品）。生成器已加保护（`--rewrite` 可强制）。

## 当前交付范围

- **只做姿态**：车头朝向 ψ_body、运动方向 ψ_vel、两者之差 β。
- 比例尺标定与物理单位换算（px/s → m/s）**已明确延后**，不属本阶段。
